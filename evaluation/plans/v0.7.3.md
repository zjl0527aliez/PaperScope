# PaperScope v0.7.3 候选计划

## 现状与证据

- 2026-10-29 12:31、12:42、12:44 的三轮本地缓存均来自 DeepSeek `deepseek-flash`。
- 第一轮使用 prompt v4，后两轮使用 prompt v5；三轮均只有种子核心分析、相关工作与综合判断，没有 `seed-evidence`，因此属于摘要材料路线，不是开放全文详细分析。
- v5 的结构完整性和证据边界较稳，但相关工作中出现过非官方中文方法名，综合判断也出现过“材料未提及”被写成“不依赖/不使用”的确定性否定。
- 旧运行没有保存完整报告与运行凭证，服务关闭后无法恢复 Token、耗时、OpenAlex 来源状态和确定性评分。

## 已进入候选版的改动

1. prompt 版本推进到 v6，旧 v4/v5 缓存不会复用。
2. 相关工作保留论文名、方法名和缩写的原文写法；没有官方中文名时使用“该工作”，不自行创造译名。
3. 对 `difference` 和 `thesis` 增加否定性事实边界校验：材料未明确支持时，不允许写成“不依赖”“不使用”“未采用”或“无需”。两次模型修复仍失败时使用透明边界句降级。
4. 实时报告记录服务端耗时，并在 `runtime/research-runs/` 安全保留最近 24 份结构化报告；归档递归移除 API Key、原始全文和 `sourceText`。
5. ReASC 评测增加摘要、自动开放全文和本地来源三种材料模式，以及摘要/全文成对捕获命令。

## 下一轮 DeepSeek 验收

启动服务并在页面激活 DeepSeek 后运行：

```bash
python3 scripts/benchmark.py pair --label v0.7.3-deepseek
```

### 摘要版

- `materialQuality.level` 为 `abstract-only`，且详细模式明确标记降级。
- 不生成伪装成原文事实的实验设置、公式、消融或失败案例。
- 相关工作不出现自创中文方法名；否定性差异均带“摘要未说明/仍需原文核验”等边界。
- 六个 ReASC 事实锚点不要求全部命中，但命中的数值和对象必须准确。

### 自动开放全文版

- `materialQuality.level` 为 `full-text`，来源为已验证 HTTPS 开放 PDF。
- 模型阶段包含独立 `seed-evidence`，且 `stageCount` 比摘要版多 1。
- 六个事实锚点全部命中；实验设置、发现和精读指南来自正文片段，不由透明降级句凑数。
- `schemaFallbackCount` 目标为 0；若非 0，逐项检查是否只是低风险边界补足。

### 成对对比

- 两次均成功并各自保存 `report.json`、`score.json` 和服务端安全归档。
- 对比总分之外，必须同时检查事实边界、材料范围、总 Token、模型调用次数、质量修复次数和耗时。
- 全文版允许消耗更多 Token 和时间，但新增消耗必须换来事实锚点、实验细节或精读价值；若只是文字变长，则继续压缩材料选择与提示结构。

## 测试后决策

- 若摘要版仍产生自创译名：增加原文术语回显校验，不扩大模型上下文。
- 若全文版事实锚点缺失：优先调整章节筛选和证据阶段输入，不增加相关工作 token。
- 若 token 明显上升但评分不升：缩减相关工作数量或每篇说明预算，并保留种子论文证据阶段预算。
- 若耗时主要来自 OpenAlex/PDF：分离全文获取耗时与模型耗时，再决定是否增加来源缓存。
- 达到上述边界后再将版本从 v0.7.2 提升为 v0.7.3。
