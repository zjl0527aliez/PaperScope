                    DEEP RESEARCH

                    详细模式需要更完整的材料

                    当前没有上传 PDF 或粘贴正文。PaperScope 可以使用 OpenAlex 返回的开放获取链接查找 PDF；只读取公开 HTTPS 来源，会校验文件类型与论文身份，且不写入磁盘。

                    查找开放全文

                    若找到可验证的 PDF，将自动提取正文后启动研究。

                    仅使用公开摘要

                    速度更快，但方法细节、实验数字和局限会更保守。
                    MATERIAL FALLBACK

                    未能获取可验证的开放全文

                    你可以停止本次研究，或明确同意改用 OpenAlex 公开摘要。如果继续，报告将标记为“详细模式材料降级”，不会冒充全文分析。
                    LOCAL RUNTIME

                    API 配置

                    在这里连接模型与 OpenAlex。密钥只提交到本机 PaperScope 后端并保存在当前进程内存中，不写入文件或浏览器存储；关闭服务后自动清除。

                    内存配置

                    激活前会进行一次真实连接测试；成功后页面不会回显密钥。

                    OA
                    OpenAlex 免费 API Key

                    免费账户每天 $1 预算，约为匿名模式的 10 倍；论文检索和引用网络共用同一个 Key。

                    匿名模式
                    尚未读取个人额度；匿名模式仍可继续使用。
                    模型阶段缓存

                    只保存通过结构校验的阶段结果，不保存 API Key、原始提示词或论文材料；更换模型、材料或提示词后自动失效。
